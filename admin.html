🔀 Trạng thái System Prompt

        
Bật/tắt áp dụng system prompt cho chatbot

        

          

            
Bật System Prompt

            
Khi bật, prompt bên dưới sẽ được gửi kèm mỗi cuộc trò chuyện với vai trò system. Trang chat nhận ngay qua storage event.

          

          

        

      


      

        
✍️ Nội dung Prompt

        
Viết hoặc chọn preset để bắt đầu. Hỗ trợ biến: {{date}} {{time}} {{lang}}

        

          
          
        

        

          
          
          
Prompt được đặt ở role: "system" trong mỗi request. Mô tả nhân cách, nhiệm vụ, giới hạn và phong cách trả lời.
